# 旧终端 UI 素材

本地独立预览采用用户选定的第二张UI概念作为美术方向。三个PNG由内置imagegen生成，透明外缘；没有把概念图整张铺成不可操作页面。

- `frame.png`：深橄榄黑金属、灰白替换角、螺丝、磨损边和少量青蓝灯；中央透明，用210px九宫格切片构成真实界面外框。
- `yellow.png`：暗黄掉漆机械按键面，无文字；220px九宫格切片，文字和交互仍为HTML。
- `cream.png`：灰白旧塑料按键面，无文字；240px九宫格切片。

生成提示要求：正视、无透视、四边中段可拉伸、无文字，材质与参考中的廉价旧消费电子一致；按钮中心相对平静，容纳动态中文文字。资产由CSS消费，保留原生成文件并另建作品目录硬链接。

实际装备缩略图来自`models.js`的现有GLB渲染缓存，256×160透明PNG data URL，复用主WebGLRenderer及环境光，不增加WebGL上下文或调用生成API。名称、规格、安装方向、血条、冲挡、选物与结算均保持真实状态。
