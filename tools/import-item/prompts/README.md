# 内置改图提示词

`cli.mjs photo` 按 `--category` 选这里同名的 `<category>.txt`，整份原样发给改图一步；`--prompt` 可以换成自己的文本。每类一份，不互相套用。画风最后由凡朔定，这些是起点稿。

| 品类 | 来源 | 实测 |
|---|---|---|
| scissors（刀） | 凡朔 PR6 用的刀提示词 | 跑过 G1-Turbo |
| pot（锅） | Wren 实测（开发归档/Aholo接入评估/wren-实测） | 跑过 |
| broom（扫把） | Wren 实测（开发归档/Aholo接入评估/wren-实测） | 跑过 |
| lamp（台灯） | Iris 照上面三份的写法补 | **未实测**：没有真跑过改图和生成 |
| slipper（拖鞋） | 同上 | **未实测** |
| pillow（枕头） | 同上 | **未实测** |

三份未实测的写法和刀、锅、扫把一致：先说保留照片里主体的轮廓、比例和原有颜色，再加同一套废土修补（剥落工业黄漆、黑黄警示纹、锈迹划痕、旧布缠绕和补丁、少量暗红布条），再写不要改品类、不要加尖刺这类会改变手感的东西，最后是浅灰背景、柔光、单件。和那三份不同的是，它们不针对某一张照片，所以只写这一类东西共有的部位。拖鞋和枕头在游戏里是软的，所以不加金属件。
