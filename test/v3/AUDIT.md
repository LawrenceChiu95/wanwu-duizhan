# v3 实现与证据

## 当前结论与证据范围

本次先交前端契约与可复现样例。`RESULT.md`面向阅读，`SPEC.md`是实施前写下的范围及验收。补充后的正式560局已经写出，旧/新回放导出途中按资源通知暂停；同装配运动消融尚未重跑。历史560局另存，不当本次结果。

- 新入口 `sim/v3.js`、参数 `sim/v3-rules.json`；旧 `sim/index.js`、`sim/math.js`、`data/catalog.json`及现有网页未改。
- 按品类保留8件的等比尺寸和质量。六锚点由凸包沿锚点方向的内侧支撑面定位，旋转沿XYZ弧度；不允许重复物品id。
- 真实球核和挂件的碰撞体在同一刚体内，各自HP；真实接触流形遍历完才选最大冲量的一对。伤害、反震先一起算，再碎件、判核是否归零。不会把件伤算成核伤。
- 拆件保留主体角速度，新线速度＝旧线速度＋角速度×（新质心－旧质心），所以幸存材料点速度连续；破碎件提供自身点速度供前端播碎片。
- A按冲量、硬度分档；B按接触后的攻击防御、硬度分档；攻守沿用质量平方根、迎击速度、2倍克制和端部速度。3%反震，主攻触弱点才抽50%种子概率；普通/真暴击上限分别为挨打部件最大血量30%/40%。
- 核归零才有胜方；60秒核都在是平局，不按剩血百分比判胜。去掉圈伤、圈外判负、被动耗血。

## 节奏和刮蹭怎么数

`probe.mjs`按时间去重正伤害的hit/weak/旧crit，与Wren约定一致；同时另报有真实冲量的contact起点。一次双向伤害不计两撞。局尾从最后一撞到终局的等待单列，不能用短的相邻间隔掩盖最后几十秒空转。

持续接触检查：每个60Hz物理步，有实际碰撞冲量，或当前形状间距≤2毫米，记为接触帧；连续达到0.1秒才作为刮蹭段，报告次数、总时长、最长段。持续段超过0.1秒后的重复冲量不产生新的攻击；起点真实冲撞可计一次。2毫米为检测容差，0.1秒为本轮明确的统计阈值，不是“好不好看”的结论。

`contact-proof.json`来自特意去掉反冲/自转/追击、零开局间距的2秒裸核测试。它只验证持续接触分支，不计入正式参数矩阵；8组测试检查持续段里没有新伤害。

## 已发现但不能冒充通过的风险

1. **时长未全过**：台灯/剪刀A种子1，核心被多次直接碰到，12.43秒结束。没有强制拖到20秒；全矩阵共有71个短局。
2. **掉件后长时间绕转**：当前台灯/扫把A种子5，在17.23/21.77秒各掉前件，此后只剩核与后拖鞋，最后38.23秒无有效撞击。`batch/example-longTail.json`是完整当前回放。`surface-proof.mjs`独立重建这条回放的活核/凸包，22–60秒每整秒39个采样中，最近表面仍至少相隔11.60厘米，切向相对速度持续；`batch/surface-proof.json`存逐样本距离。这是静态重建，不重新跑对局。证据说明双方没有碰到，不能靠放开近静止伤害来修。中心吸引与指向对手的追击都是沿中心连线，不能直接消掉绕转的切向分量，掉件后外形变小会错开；是否通过追击方向修正且保住反冲，要在隔离对照中验证，本轮没有拿强制扣血掩盖。此前B种子5也出现同类现场，留历史，不与当前A混用。
3. **位置校正可能影响观感**：旧8次法线分离在组合凹口振荡，历史最坏残余5.5厘米；新增按质量分担、保持整体质心的径向分离搜索，不改速度/血量。当前`breaks`样例校正后残余≤0.5毫米，但最大额外径向分离15.65厘米。不能用残余小冒充不跳动、不穿模或惯性已通过；全矩阵最大额外径向分离27.47厘米；不能作为不退步证据，需Lead/Wren并排实播。`maxPositionCorrection`是一个物理步内校正路程之和，并非单个主体净位移。
4. 当前自转5rad/s，不再加速去追统计线。反冲仍0.85m/s，但方向、强吸引下的轨迹和掉件后的质量都变了，参数相同不等于手感不退步。

浏览器模块验证：临时在127.0.0.1:4488提供仓库根目录静态文件，顺序运行`browser.mjs`、`browser-node.mjs`，随后关闭自己的HTTP服务和Chrome。不得覆盖4330的现有服务。
