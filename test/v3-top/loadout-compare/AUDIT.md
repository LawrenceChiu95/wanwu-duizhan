- run.mjs记录逐局回放SHA、首次碎件、核心命中、时长与冲挡，输入逐文件SHA在results/inputs.json；失败即抛出，不读旧批次补数。

- 单元测试覆盖反震与主攻区分、同时碎件、无碎件、平局分母、并列最优和种子缺口；当前4项通过。

- 复跑：nice -n 20 node test/v3-top/loadout-compare/run.mjs 100 <新目录>。旧结果使用wx保护，不覆写。finish.mjs固定核本次results，并生成本报告及samples；复跑先自行指向新目录，不能混用。
