# 自动录屏样本

冻结版本 d08a698f7bc8c710279afc6929418bf5858448ed，模式 A，对手固定为锅伸出／台灯贴着、对面。每对两条只改装法，种子相同；样本来自每格100局的最好／最差装法。并列时按预先枚举顺序取第一种，种子按两格典型时长选择；不是承诺每个种子都翻转。

录屏只做自动，冲挡电脑对电脑仅报数。打开下面的本机地址（4330 当前已在服务，不要开旧4399），核两件东西、朝向和位置，再点“开打”。不要切手动、换物品或重新随机种子；URL带seed会固定。优先各录一段整局，再取碎件／核心命中附近，保留前后约2秒。发布页外层的查询串不会自动传给内嵌游戏，因此不用外层链接代替这些地址。

Wren先核游戏控制台 window.__top.status() 的 seed/mine，并在模拟完成后对 window.__top.replayJson() 原字符串做SHA256，与下表核对；不一致先停并找Sol，不替换录屏源或重新构建。Browser实际SHA回执见 browser-verification.json（有回执才算已验）。
