## 做什么
1. **陀螺式挂法**（sim/）。核心球绕自己的「上」轴高速自转，赤道一圈有固定挂位（`v3-rules.json` 的 `top.slots`，每 45° 一个）。每件道具选一个挂位和一种朝向：
   - **伸出去**：最长的那条边沿半径朝外，最薄的那条边朝自转轴（像刀片平躺在旋转面里）。哪头朝外按品类写在 `top.outEnd`（扫把是刷头、锅是锅身、剪刀是刀尖）。
   - **贴着**：最长的边顺着自转轴竖起来，最薄的边朝核心，宽面贴住核心一侧（像盾）。
   - 两件不重复、挂位不重复；转起来只有「两件之间隔多少度」有意义，网页给「对面（180°）／挨着（90°）」两种。
2. **转起来**：开局就在转。自转靠一个有上限的力矩维持（重的、伸得远的转起来慢、被撞慢了恢复得也慢）；被撞歪了会慢慢自己扶正，旋转面大致保持水平，方便两边的刀片在同一个面里相遇。
3. **节奏**：保留「靠近 → 甩出去撞 → 弹开」：撞上后两边沿法线各弹开一下（反冲速度不低于 v1 的 0.85 m/s），停追一小段再追。新增：追击时消掉两边相对绕圈的切向速度（修掉件后的空转，原因是吸力和追击都沿连线、消不掉切向速度，两边一直错开）；位置校正每步限幅，去掉一次跳 27 cm 的径向搜索（修分离跳动）；伤害和血量一起调（修短局）。
4. **决定输赢那一下**：沿用慢镜头；回放里给出结构化的原因（谁的哪件、伸出去还是贴着、打中了核心还是道具、输家当时还剩几件），网页把它说成不超过 20 字的一句白话。
5. **网页 demo**（web/）：
   - 装配：选两件（锅、扫把、台灯、剪刀、拖鞋、枕头；锅和台灯用 Lux3D 生成的带贴图模型），每件点一下切「伸出去／贴着」，再点一下切「对面／挨着」；上方是自己这台陀螺的实时 3D 预览，点了马上变。默认装法直接能开打。对手是固定的电脑装法。
   - 对打画面：核心球发光、一眼可见；转动有拖影扇面；撞上有闪光火花；道具碎掉时模型从核心上脱落、碎片飞开；核心血和道具血用最少的小条表示，不堆文字。
   - 打完：一句白话原因 + 「换个装法再打」回到装配。
   - 手机竖屏为主，300 px 和 390 px 两种宽度验版面。
6. **发布**：Raft Artifacts `wanwu-top-demo`，游戏放 `play/`，首页一个大按钮；manualChunks 拆包分批发；发布副本加 `window.createImageBitmap = undefined;`；对外不带 agent 名和内部路径；可见范围不改。

## 不做
自由黏、三件以上、圈伤/慢扣血、按物品写死胜负、一直加转速压空档。手动模式只有「冲」「挡」两个键，不做攒格子、三格叠加、升级和等级。

## 加一个手动模式（10-27 晚加的范围）
- 来源：远夏 #万物对战:2db22844 里的 80a59794「冲和档都加吧，攒格子慢点加，现在可以做吗」；Elara 裁决 428deaf5。
- 自动版原样保留当对照：同样的装法，同一页上有清楚的「自动 / 手动」切换。
- 手动模式里陀螺照样自转、照样被中心吸，玩家只按两个键：
  - **冲**：点一下 → 约 0.3 秒看得见的蓄力（发光或下压）→ 整台陀螺明显比平时快地扑向对手，撞得更狠 → 冷却约 4–5 秒，按钮上一圈扫过去表示冷却。
  - **挡**：点一下 → 核心上约 1 秒看得见的护盾光，期间受到的伤害和击退大幅减少；挡住对方的冲时，那一冲明显被弹开，这一下要一眼看懂。冷却约 5 秒，显示方式同上。
- 电脑对手也会冲和挡：简单规则加一点随机，同一种子结果固定。
- 冲的伤害和单击封顶（Elara 10-27 晚裁决，起因 Sol d75073bd）：单击 30%、弱点 40% 的封顶管普通撞击；冲在封顶之后再 ×1.25，单击最多 37.5%、弱点最多 50%，满血核心仍至少要两下才碎。冲是玩家自己掐准的一下，封顶后不加就白按了。
- 主线不变：形状和位置还是决定打在哪里，按键只决定什么时候；同一套装法里仍要看得出是哪件打中的。
- 节奏验收线两种模式都要达标、分开报。回放仍要确定可复现，按键作为事件记进回放。
- 界面：底部两个拇指够得着的大按钮，图标加「冲」「挡」，照 frontend-design 的要求做。截图：390 和 1440 各一套，另加冲撞命中一张、挡住冲撞一张。
- 时间：自动版先收尾提交，10-28 05:00Z 前回报；手动模式 10-28 10:00Z 前回报，不稳就照实说还差什么。
- 10-27 晚补充（Elara）：按钮放在 390 宽场地下方空着的那块，不把场地往上推、不缩小场地；每次有效撞击在接触点标出是哪件撞的，顶栏同时闪出手的件和挨打的件。Sol S1：按键按物理步采样记进回放，冲/挡/弹开在确定性步进里算，加「同样按键重放逐字节一致」的测试。
- 自测：`test/v3-top/batch.mjs`（`MANUAL=1` 电脑对电脑、`MANUAL=mash` 死按玩家对电脑）、`web/scripts/manual-shots.mjs`（无头浏览器真按按钮、截图、把浏览器里实时打出的回放和 Node 按记下的按键重算比 sha256）；结果见 `RESULT.md`「手动模式」。

## 镜头（10-27 晚改，优先于手动模式）
- 来源：远夏 5740feda 手机上玩 v4 看晕了；Wren 在 390 宽实测（c489ef86 / 1bf701f1）：整帧平均 497 px/秒、最差一秒 907、8 秒里方向反转 39 次，37% 的帧对上下两半反向移动（镜头在转/滚）；Elara 裁决 98f93d28。
- 定了的：
  1. 固定镜头：开打后不跟、不转、不绕、不推拉。一个姿态：从上往下斜看（与水平约 60°），框住整个场地留一点边，两颗陀螺被撞到场边也整颗在画面里。取景只在开局（按两边装法的伸出长度）和窗口尺寸变化时算一次。
  2. 震屏只给决定性的一下（道具碎、核心碎）：几 px、不到 0.2 秒、只平移不转；拿不准就不加。
  3. 结算：镜头不动；只有赢家被结算卡挡住时，整幅画面向上平移一次（≥0.6 秒缓动，不转不缩）。决胜慢放只保留时间放慢，不动镜头。
  4. 陀螺在 390 宽显小，就给场地更多屏幕（版面），不动镜头。
- 过线（Wren 同一量法：点「开打」后 1.5 秒起，10 帧/秒截 8 秒，整帧相位相关，CSS px）：整帧平均位移 ≤40 px/秒；最差一秒 ≤150 px/秒；上下两半反向的帧对 ≤5%；位移 >30 px 的帧合计 ≤0.3 秒（震屏）；震屏只平移不转；场地边缘一圈和两颗陀螺始终在画面里。
- 自测脚本：`web/scripts/camera-motion.mjs`（截帧 + 整局安全区/场地边缘审计）+ `web/scripts/camera-motion.py`（相位相关），结果见 `RESULT.md`「镜头」。

## 不能退步
1. 撞上那一下的力度、撞完弹开的惯性：和 v1 球形版同种子比，撞击瞬间接触点相对速度、撞后 0.2 秒内两边分开的速度，中位数都不低于 v1。相对速度两版统一用撞前读法（R2：那段接触第一次有解算冲量之前的速度，算接触点沿法线的迎击速度，`test/v3-top/impact-probe.mjs`）；「不弱于 v1」以分开速度为主证据。
2. 慢扣血为 0：只有真实接触才扣血。
3. 连续刮蹭（持续接触 ≥0.1 秒）单独统计，持续段内的重复冲量不算新撞击。
4. Node 和 Chrome 回放逐字节一致（`test/v3/browser*.mjs` 照跑）。
5. 只有核心碎了才输；道具全掉也继续打。

## 验收（Elara 验收线）
- 节奏：一局 20–40 秒；开局到第一次有效撞击 ≤1.5 秒；有效撞击间隔中位 ≤3 秒、最长 ≤6 秒；慢扣血 0；连续刮蹭单独报。多种子 ≥50 局（10 分钟内跑完），报通过比例和不过的样子。
- 手感：v1 同种子并排，相对速度、分离速度不低于原来；附前后对照截图或回放。
- 平衡：不出现一件东西通吃，报各件胜率。
- 看得懂：画面能分出哪件伸出去在打、哪件贴着在挡；掉了一件以后局势变化看得出来（截图体现）。
- 网页：390 px 宽截四张（装配、撞上那一下、一件碎掉、结算），300 px 宽版面不溢出；Lux3D 模型有贴图；无长时间卡顿。
