## 做法与范围

- `mine` 和 `foe` 使用现有同一套格式检查：五段、两件不同的可选 catalog ID、各 out/hug、e180/e90，且参数各最多出现一次。缺省沿原默认装法；提供空值或错值明确报对应参数错误，不静默回退。
- 开打按钮初始禁用，正常拼装就绪后才开放；统一报错时隐藏载入并禁用开打。已有错误不能被异步就绪或返回拼装重新启用，start 入口也拒绝开打。
- 只改参数与按钮状态逻辑，沿用现有错误显示和 disabled 样式。不改 sim/data、默认装法、物理、画面布局、样式或其他参数契约；不顺手修改地址回写。

## 验收

- 没有 mine/foe 的默认局、合法 mine 与合法 foe 组合均能选装、开打、整局结束，再回拼装；默认与指定装法的回放和未改前保持一致。
- 双方各验证：空值、段数不足/过多、不存在/不可选 ID、重复道具、两个位置的非法朝向、非法挂位、重复参数（含同值）；显示对应错误、载入结束、开打保持禁用且未初始化对打。
- 拼装就绪后报错：鼠标点击与 start 入口均不能开始；刷新正常链接后恢复可玩。异步载入期间报错，即使之后完成载入也不能重新开放按钮。
