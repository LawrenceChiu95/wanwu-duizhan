# 长局回归使用独立种子

来源：channel task #20，Elara对PR26原审查S3/S4的后续安排。只改测试和CI，不改物理、数值或玩法。

## 首次执行前固定

- 起点 mvp/base 0c5556b，固定种子40000–40099，每个连续种子都跑，不按结果挑选。
- 沿用v13固定六场景及其默认对手，每场景100局，共600局；沿用原四局的A公式、双方择时AI、0.25秒挡窗。没有新装法或参数搜索。
- 通过标准沿现行整批长局口径：超过45秒的比例≤0.5%，达到60秒的比例≤0.01%。600局对应最多3局超过45秒、0局达到60秒。各场景单列实数，单格不另判零尾部。
- 首跑前写下种子、场景和七个物理/数据SHA；执行完整个面板才看结果。失败保留全量记录，不换种子、删场景、调参或改门槛求通过，交Lead裁决。
- 这600局是固定回归面板；首次相对调参数据独立，以后是已用回归种子，不再宣称每次CI都是新样本。不能替代正式三模式时长、择时、镜像、墙面和S池验收；不以小样本0次推断总体0.01%置信上界。
