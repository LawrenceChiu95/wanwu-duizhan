# 结算提示按具体件的长处判断

来源：channel task #17、Elara 3446654a；目标 mvp/base。Sol 只改提示判断，Iris 原界面和 tipLine 返回一句话的接口保持。

- 当前问题：范围型伸出件先碎，旧规则一律推荐改成贴着，会反着教玩家。
- 判断输入：该件 rating.scores 的攻击、范围、耐久，不按品类或总等级代替。
- 攻击或范围的较高分大于耐久：适合伸出；输局中若这类件贴着，建议伸出并换另一件贴着。伸出先碎时建议抓准挡的时机，不反转朝向。
- 耐久大于攻击、范围两项：偏守；伸出先碎时允许建议改成贴着。
- 两边相等、或该件缺三项记录：不臆造专长；伸出先碎时给挡的时机建议。
- 赢局文案、零输入引导、其余冲空/被挡等顺序保持；不改伤害、几何、胜负和评分。

验收：两个默认扫把伸出碎不推荐贴着；贴着的进攻型件落败推荐伸出；防守型伸出件碎仍可推荐贴着；同品类不同分可得不同建议；并列/缺分不捏造偏好；赢局和零输入引导不退步。纯函数测试读真实九件和小型反例，加入现有 CI。
