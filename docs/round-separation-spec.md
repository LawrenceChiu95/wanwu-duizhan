# 一合一分

以 #122 的玩法为基线，默认锅伸出、抱枕贴身，三关共 72 局（每关同样的 24 个种子，看闪光后 0.25 ± 0.08 秒按挡，完美后接冲）。源码确为平撞回弹 0.75 m/s、每边径向速度封顶 1.0 m/s、场地吸力系数 6。实测一局有效碰撞中位数为 65.5／89／52.5 次，估计的 68–91 次只适用于第二关附近。一次碰撞按物理日志的接触事件计。

| 相邻碰撞间隔中位数（秒） | 0.70 | 0.70 | 0.79 |
| 连续贴身至少 0.10 秒的时间占比 | 0.023% | 0% | 0.083% |

短碰撞也计入贴身占比的逐步测量另跑一遍。主要问题是回到下一次碰撞太快、平撞往往没有拉开足够距离。对手起蓄点用此前最近一帧估计（最多差 0.033 秒）。

## 规则

- 新规则存入回放的 `combatRules.round`。显式选择时才用。历史回放和 `?feel=old` 仍用原参数和事件。
- 独立交锋的第一个有效接触就弹开。已经接触时，真正冲进来或接住冲仍可触发。沿核心连线去掉向内的速度，以每边设定的向外速度分开，保留少量切向速度。平撞和勉强对等，冲中让受撞方更远，双冲双方都远，完美挡让冲方最远并沿用原来的晕眩。
- 弹开后约 1 秒，暂停贴近和削减横向运动的力，中心牵引降到约一成，加同向切线力让双方沿外圈走一段。手动操作始终可用。
- 只有普通接触和擦边削减伤害。完整冲中与接住冲的伤害计算沿用。平撞遇举盾不消耗盾窗，也没有格挡结果。
- 对手在蓄力期间持续刹车。按当前接触距离和相对速度估算冲到时刻，预计剩约 0.35 秒时发一次闪光信号，过远时可在冲出后发。对局的冲挡输入、完美与勉强窗保持原样。
- 每次有效弹开产生一条 `exchange`，含 `t`、`point`（世界坐标）、`normal`（0 指向 1 的水平核心连线）、`kind`（`bump`、`dash`、`clash`、`perfect`、`tight`）。普通撞点音画只接 `bump` 一次，原来的冲挡反馈仍接原事件。每次对手冲最多发一条 `dashCue`，含 `t`、`side`、`pressStep`。
- 用同一组种子比较前后，每关 24 局看闪光并跑另两种打法，第三关跑 96 对种子。另查同平面、开场、抱枕接触、旧回放、带椅子与陶瓷件。
