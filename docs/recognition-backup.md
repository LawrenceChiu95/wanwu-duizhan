授权：Elara，#万物对战:8ea1b114 msg=63661b6b。仅隔离实现与假供应商验证；不更新4330/4331、不部署、不创建百炼账号或调用付费接口。

## 实现约定

- 入口仍是 realGenerator → recognizePhoto，任务、身份、额度和付费建模流程不变。默认只调用原 Gemini；设置 `SHOOT_RECOGNITION_BACKUP=qwen` 并提供百炼北京工作空间地址及 Key 后才允许备用。
- Gemini 正常时不发备用请求。备用开启时，主通道最多两次、每次最多15秒，中间隔2秒；网络连接/超时、Google 5xx 重试后转备用一次；429 直接转备用。鉴权及其余4xx、格式错误和照片不清不触发切换（Elara msg=1bc198cc 修订）。
- 总等待上限55秒（含缩图、主通道、间隔、备用和读回包），每次请求上限15秒。到期取消请求，禁止后台继续新发请求。备用失败时保留主通道故障码及其原任务重试规则，备用错误仅记入诊断。备用明确识别为照片不清时，照原照片不清规则返回（Elara msg=c251e648）。单次操作最多调用备用一次。
- 备用使用 Node HTTPS 独立 Agent，不读取本机代理环境。只准北京工作空间 HTTPS 地址、无重定向；SSE流最多256KiB，合成文本最多64KiB。不把 Key、照片、响应正文或错误原文写入日志。
- 固定候选 qwen3.5-omni-plus，文本输出上限1024，按官方要求使用SSE流并校验完整结束；只剥掉完整包住输出的一层 JSON 代码围栏，再用原字段规则校验，不从解释文字里截取JSON，不补默认属性。
- 已有8张匿名官方演示的原始文本作为格式回归样本；它们不是物理属性金标，不在仓库分发原照片。
