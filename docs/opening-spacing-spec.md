# 开场留出反应时间

来源：#万物对战:fda439b0，Elara 裁决 b9d6e779，执行帖 2621157e。基线为评委版 d4993b8。现行开场按双方扫掠半径加 0.35 米摆放，第一步起就向中间加速。

新手感把三关默认装法无输入时第一次接触的中位数移到 0.8–1.0 秒。先量只拉开初始间距的效果。若进场位置或关卡节奏变化过大，再试开场一小段平移加速度渐入。冲、挡从第一步就可用，「开转」照旧。把所选开场参数存进现有回放规则；旧手感与未记录该参数的历史回放继续走原开场。

验收用三关原对手、原装法、原 AI 与同批种子。记录无输入、熟练和乱按的第一次物理接触，熟练和乱按另记胜局、局长。再用一批未调参的种子复验，并核 390 宽两颗陀螺和开场操作。保留耐久、伤害、拍照、陶瓷炸片及冲挡参数。难度或局长变化明显就把数据交 Elara 裁决。

单拉间距时，莽牛和长臂猿在开场马上蓄力，较早撞上。候选间距取 0.95 米。长件的额外间距以扫掠范围能容在场内为上限，极长装法保留原始间距。开场平移吸力和追击加速度从零线性渐入 0.70 秒，第一次有效接触后恢复全量。对手在最初 0.40 秒且还未接触时不发起冲刺决策，挡、冲刺反应延迟和蓄力长度沿用原规则。玩家抢先冲可以提前接触。

## 首条冲刺教学的时间

来源：#万物对战:fa18a1da，Elara b3365358。格挡新版中，对手在对局时间满 1.5 秒前不能发起冲刺，即使已经碰撞。玩家仍可从第一步冲、挡。对手蓄力、冲刺、格挡和伤害参数沿用。新开场参数跟随回放，旧手感和没有该参数的回放保持原规则。

用开场 1.5 秒内已经接触的对局核对对手首次蓄力时间，并复测三关。同一份回放的规则重新模拟时，结果应逐字节一致。
