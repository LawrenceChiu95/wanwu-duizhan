## 下载与使用

- [下载完整接入包 ZIP](aholo-wasteland-handoff-v1.zip)（约30MB；GitHub若不预览，点 Download raw file 下载）。
- [接入契约](INTEGRATION.md)：接口、状态、失败恢复、计时定义和游戏侧处理。
- [压缩包 SHA-256](SHA256SUMS.txt)。

解压ZIP后，先读包内README.md。samples/ 中的“刀-Turbo.glb”是用户确认够用的结果；另附废土参考图与G1对照。锅样例仍是G1，不能算锅的Turbo验收。

api/ 包含 Python 标准库独立测试入口与刀具实测提示词。在该目录运行：

```sh
python run_turbo.py --photo "自己的照片绝对路径.jpg" --run item-001
```

程序会隐藏输入自己的国际站Aholo密钥；密钥只存当前进程内存，不需要安装额外Python依赖。调用会上传照片并创建收费生成任务。其他物品先改 prompt.txt 中的类别与保留特征，不能把刀具文本直接套在锅或枕头上。

包内程序是独立复测工具，不是可直接挂到前端的生产后端；不得让前端持有API Key。打包版已检查语法、CLI和请求参数，未对打包版重新付费跑完整链路；接口各阶段已有真实调用结果。

## 建议先接什么

先完成一种居家物品的闭环：拍照上传 → 任务状态 → 保存GLB → 等比例统一游戏尺寸、配置独立碰撞体 → 入库 → 参与现有拼装对战。尺寸、碰撞和扣血规则需与Sol/Elara对齐，遵循仓库CONTRIBUTING约定。

还需要补：后台任务持久化、刷新恢复、失败处理、资产存储、类别规则和游戏内性能验收。生成成功但下载失败应重试下载，不能重新生成。创建请求超时应先核对任务，不能盲目重复扣费。

本包不含密钥、私人原照、运行状态文件、日志或临时资源链接。只新增交接资料，未改动游戏运行代码。
