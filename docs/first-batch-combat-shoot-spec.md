# 第一批对撞与拍照生成

来源：Raft #万物对战:207a725b，远夏反馈及方向见 #万物对战:b5cffa43。基线 `03c2e53`。物理、后台各自可验证，界面由 Iris 实现。

## 对撞

- 位置判攻试验版将两颗核心固定在场地的 y=0 平面。保留场心吸引、相向追击和可见回弹，单次撞击使用平面分量解决平移。
- 0.30 秒蓄力中跟随对方核心，起冲前 0.08 秒锁定。冲挡的预告、蓄力时间、冷却和挡的时长沿用。事件提供箭头更新方向与装法的无遮挡冲距。
- 放宽宽重件弱击减伤，先验最多减半。分析 49 张体感样本和真实成品分档，按现有攻击、范围、耐久总分给提档建议。
- 同种子对比默认、椅子、桌上小件分别打三关，记录冲空率、高差、胜率、局长、超过 45 秒比例、击中伤害和追击节奏。关差沿用当前验收，评委版继续用当前包。

## 生成

- 对照两套当前任务账调查凡朔反馈，记录证据可确认的失败阶段和计费。认物 5xx、超时自动再试一次。每单最多自动重试一个生成阶段。上游明确拒绝创建且并发已满时，等约 8 秒再提交同一阶段，进程重启后也遵守已保存的最早重试时间。上游报告任务失败时，须在历史记录里核到同一任务的实扣为 0 分才重试。丢失付费提交回执、退款未确认或已扣分沿用原人工处理。失败与重试日志带时间及本地任务号。
- 改画风图片落盘即在所属任务回包提供 `styledUrl`。沿用带会话取图接口，其他会话仍不可读，3D 和库存等成功后才开放。认物回包沿用 `name`、`materialName`、`material`。
- 用独立数据目录、假模型和模拟供应商检查完整流程、中间取图、跨会话拒绝、失败一次恢复和再次失败、重启及付费提交不重复。本轮无真实付费、无线上后台重启。独立试玩页的拍照仍关闭。
