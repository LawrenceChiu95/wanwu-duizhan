## 界面接口

```js
item.rating = {
  version: 'rating-v1:100-48-100:75-60-45-30-0',
  scores: {attack:100, range:48, durability:100},
  letters: {attack:'S', range:'B', durability:'S'},
  grade: 'S'
}
```

分数为 0–100 整数，由离线脚本写入；界面通过同一评分模块的 ratingOf 按有效分数核出字母和总等级，不重新从物件属性算分。总等级直接用三项整数之和除 3 比较；显示平均可保留两位，但比较前不先四舍五入。S/A/B/C/D 下限为 75/60/45/30/0，等于阈值归上档。

version 是算法、三分和阈值的稳定标识。同件改名、换图不重翻，分数或定级算法改变才换。厘米公斤继续读现有 bounds/mass，不放进 rating。

## 分数依据

默认九件使用设计表的质量、归一化实长、材质、新旧。废土刀和废土锅的 worn（有点旧）是明定的游戏设计，不从画面锈迹推断；现场认物未知新旧仍按 unknown 中性处理，不从画风猜。

- 攻击：round(100 × sqrt(mass/2.5) × hardness/1.2 × 新旧攻击系数)。
- 范围：round(100 × 归一化最长边/0.8)，最长边先量化到微米，避免浮点误差改变半分边界。
- 耐久：round(100 × 四次方根(mass/2.5) × 材质韧性 × 新旧耐久系数)。

先裁到 0–100，再求平均。材质韧性 metal1、wood0.8、plastic0.65、cloth1.4、rubber0.65 是本轮已验收的游戏系数。新旧 intact/unknown 为 1/1、worn 为 .95/.9、damaged 为 .6/.5；默认九件的 intact/worn/damaged 是明定设计；新导入缺 condition 仍 unknown。

算法真源 [sim/item-rating.js](../sim/item-rating.js)，重算 `node tools/rate-items.mjs`。新导入也在写 catalog 前生成同一套评分；旧任务续接遇到已有项不改其评分。认物新增大小、材质、新旧仍属于现场生成阶段，本轮不花额度。

## 重算与证据

`node tools/rate-items.mjs` 与导入器共用 `.aholo/catalog-lock`。锁内读取最新清单、重算并原子保存，已有写入者时直接报锁占用；确认没有写入进程后才可清理遗留的空锁目录。新导入不会被旧清单覆盖。默认九件的唯一名单是 [default-item-designs.json](../data/default-item-designs.json)，新增件不计入默认集合。

初版交付的 `first-grades.json`、`tests-initial.txt`、`import-initial.txt` 是历史表和运行输出，已移到共享开发归档「等级数据收尾/historical」，SHA见同归档archive-sha.json；当前等级只从catalog和评分函数读，不维护第二张数字表。
