# 外伸件接住冲刺时判挡

依据 #万物对战:fa18a1da，Elara ce4dd3cf、Wren 1463d6bc。六局里盾开着接到对手冲撞 42 次，只有一次撞到伸出的抱枕却判了挡空。现行规则用完整冲中的门槛来判挡。偏离接触面法线时，冲已撞实、结算为擦边，但盾窗没用掉，后面才报挡空。

新手感中，冲手确实向对方推进、实际接触面正在合拢，并达到原有最小碰撞冲量时，盾接到这一下就判挡。新接触沿用原先的擦边判据；已贴身时仍须达到原有冲中使用的接触面合拢速度，避免把相擦判成出冲。普通碰撞只减伤，盾窗继续。完全命中与擦边的伤害、完美和勉强的时机及效果沿用原规则。新判法写入回放规则，未存此项的回放以及旧手感按原规则重算。

用固定输入复现外伸抱枕接到擦边，查接触发生当帧的判定、盾冷却和回弹。复查普通撞击不消耗盾窗、已贴身时的冲撞及两档时间边界。第三关按上一批种子重跑，旧手感和历史回放与现行评委版逐字节核对。
